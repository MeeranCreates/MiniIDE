# MiniIDE

A lightweight desktop IDE built from scratch using Python and PyQt.

## Goal

MiniIDE is a learning project where we build our own IDE step by step, understanding each part instead of copying a complete codebase.

## Modules

* Python
* PyQt5

##  Project Structure

```text
MiniIDE/
├── main.py
├── requirements.txt
├── .gitignore
├── core/
├── ui/
├── widgets/
└── assets/
```

##  Status

Currently in development.

##  Learning Approach

**Understand → Write → Test → Level Up**

Features will be added progressively as the project develops.
